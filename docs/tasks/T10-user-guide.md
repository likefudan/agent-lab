# T10 使用文档与客户端接入

- 依赖：T06
- 对应设计：第 6.3、6.5 节
- 预计规模：小（只写文档和示例）

## 目标

让第一次使用的人能按文档在 15 分钟内（不计模型下载时间）完成部署，并把常用工具接到本地端点上。

## 范围

做：

1. `docs/user-guide.md`：
   - 快速开始：bootstrap → pull → gpu-limit apply → serve → 第一个请求；
   - 日常使用：启停、查看状态、切换档位、打开思考；
   - 卸载：revert GPU 上限、删除目录；
   - 常见问题：内存不足、端口占用、速度慢、模型下载中断。
2. 客户端接入示例（`examples/`）：
   - `curl`；
   - OpenAI Python SDK（普通和流式）；
   - Aider 指向本地端点的配置；
   - 通用说明：任何支持自定义 OpenAI base URL 的工具如何配置。
3. 示例脚本在 CI 中用小模型跑通。

不做：网页界面；自动启动配置。

## 验收标准

- [ ] 按文档从零操作一遍（设备测试），记录实际耗时，文档中的命令全部可以直接复制运行。
- [ ] `examples/` 中的脚本在 CI 中通过。
- [ ] CI 全部通过。
